Shared lists of SNOMED CT concepts, ready to use

A value set is the list of SNOMED CT concepts that fits one purpose, such as every kind of asthma a registry should count. Define it once, publish a version, and anyone can use the same list.

Browse published sets

Browsing and downloading published sets needs no account.

How a value set is made

  1. Define

    Write an ECL rule, or pick concepts one by one. The list of concepts updates as you go.

  2. Publish

    Fix a version against a SNOMED CT release, so everyone using it gets exactly the same list.

  3. Share and download

    Share it with the community and download it as a Global Patient Set file or a FHIR ValueSet.
